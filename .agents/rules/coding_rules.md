# Rules: Python Coding Standards for Sync System

## 概要

このルールは、本プロジェクトにおけるPythonコードの品質と一貫性を担保するための常時適用（Always On）される規則です。

## 規約リスト

1.  **型ヒントの徹底**: Pythonコードのすべての関数、引数、戻り値、および複雑な変数には、必ず `typing` モジュールを用いた型ヒント（Type Hints）を付与すること。
2.  **エラーハンドリング**: `try-except` ブロックを使用し、API呼び出しエラー時には `logging` モジュールを用いて詳細なエラー内容（HTTPステータスコード、レスポンスボディ、リクエストのペイロード）を出力すること。`print()` はデバッグ目的以外での使用を禁止する。
3.  **フェイルセーフ設計**: 破壊的更新（Google Docs上のタブ削除など）を行う前には、必ず対象のオブジェクトが存在するか、IDが正しいかを検証する事前チェックロジックを含めること。
